# LSTM News Text Generation

A character-level Long Short-Term Memory (LSTM) model for experimental news-text generation using Python and TensorFlow/Keras.

## Model and training summary

- Architecture: Embedding → LSTM → Dense character prediction
- Vocabulary size: 128
- Sequence length: 100 characters
- Training: 10 epochs
- Final training accuracy: 57.10%
- Final validation accuracy: 54.99%
- Model parameters: 123,520

## Important limitation

This is an educational/experimental text-generation project. Generated text may be repetitive or incoherent and is not suitable for production or factual news publication.

## Tech stack

Python, TensorFlow/Keras, NumPy, pandas, and Google Colab.
